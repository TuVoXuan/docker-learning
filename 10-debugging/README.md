# Bài 10 - Debugging Docker

> **Status: Not started ⬜**

## Nội dung sẽ học

- `docker logs`.
- `docker exec`.
- `docker inspect`.
- Debug port/network.
- Debug container bị `Exited`.
- Debug volume và permission.
- Debug PostgreSQL/Redis/API trong Docker.
- Các lỗi Docker Compose thường gặp.

## Commands quan trọng

```bash
docker logs CONTAINER
docker logs -f CONTAINER
docker exec -it CONTAINER sh
docker inspect CONTAINER
```
